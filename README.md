Un projet d'apprentissage progressif du langage Java, couvrant les fondamentaux 
de la programmation orientée objet jusqu'aux concepts avancés.

---

##  Concepts couverts

- ✅ Structure d'un programme Java
- ✅ Variables et types de données primitifs
- ✅ Boucles `for`, `while`, `do-while`
- ✅ Conditions `if`, `else`, `switch`
- ✅ Tableaux et manipulation
- ✅ Déclaration et appel de méthodes
- ✅ Paramètres et valeurs de retour

---

##  Prérequis

- Java JDK 8+
- Eclipse IDE
